# Datos de muestra

Esta carpeta no se usa. No hace falta un dataset reducido: el dataset completo de la cátedra pesa unos 13 MB, está versionado en [`data/datalake/landing/`](../datalake/landing/) y el pipeline entero corre sobre él en una máquina común, así que la demo y el Quickstart usan esos mismos datos.

Los tests tampoco leen de acá: cada uno arma sus propias rows en un lake temporario.

Queda la carpeta porque es la estructura que recomienda la consigna. Si en algún momento se agrega un dataset más grande, acá iría una muestra chica para la demo.
